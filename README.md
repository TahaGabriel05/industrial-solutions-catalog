# Industrial Solutions Catalog

Build a modern, professional B2B website for a company selling tools, hardware, fasteners, industrial supplies, industrial fittings, valves and faucets.

Create a product catalog, not an e-commerce store.

Left sidebar: “Product Categories” with categories and subcategories.

Each category has a professional cover image showing its products.

Display products in a clean grid.

Each product card shows:

Product image

Reference / SKU

Product name

Technical specifications

“Request a Quote” button

Never display prices.

Quote form should automatically include the selected product/reference and ask for name, company, phone, email, quantity and message.

No login, registration, user accounts, cart or online payment.

Add product search and category filters.

Responsive design for desktop, tablet and mobile.

Professional industrial style: dark blue, white, grey, clean typography and high-quality product imagery.

Structure the catalog as Category → Subcategory → Product.

Make products/categories easy to add and manage later.

Website language: English, with structure ready for French and Arabic later.

Include Home, Products, About Us and Contact/Quote sections.
